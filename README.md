# sideshore-site

The public website for [Sideshore](https://jctec.github.io/sideshore-site/), a wind forecast and live-station app for iPhone, iPad and Mac.

- `/`: landing page
- `/privacy/`: privacy policy (App Store privacy URL)
- `/support/`: support (App Store support URL)

Plain static HTML, served by GitHub Pages from `main` at the repo root. There is no build step.

This repo is the source of truth for the site: edit the pages here, and pushing to `main` publishes them.
